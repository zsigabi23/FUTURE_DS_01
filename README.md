# 📊 Store Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes retail sales performance using the Superstore dataset. The objective was to explore key business metrics such as revenue, profitability, regional performance, and product sales trends.

Using **Power BI**, I developed an interactive dashboard that provides insights into sales distribution, profit drivers, and the impact of discount strategies on overall profitability.

The dashboard helps identify high-performing product categories, regional sales patterns, and potential risks associated with excessive discounting.

## 📂 Dataset
The dataset contains transactional retail sales data including:

- Order ID  
- Order Date  
- Ship Date  
- Customer Name  
- Product Name  
- Category  
- Sub-Category  
- Region  
- Sales  
- Quantity  
- Discount  
- Profit  

The data was cleaned and prepared using **Power Query** before building the dashboard in Power BI.

## 🧹 Data Preparation
The following steps were performed during data preparation:

- Imported dataset into **Power Query**
- Validated data types (dates, numeric fields, and categorical variables)
- Checked for missing values and inconsistencies
- Created calculated metrics for improved analysis

---

## 🔍 Key Insights

- **Technology products generate the highest revenue**, outperforming Furniture and Office Supplies.

- **The West region contributes the largest share of profit**, indicating strong market demand and performance in that area.

- **Higher discount levels tend to reduce profitability**, with several orders showing negative profit margins when discounts exceed certain thresholds.

---

## 💡 Business Recommendations

- Optimize discount strategies to protect profit margins.
- Focus marketing and inventory efforts on high-performing product categories.
- Investigate underperforming regions to identify opportunities for growth.
